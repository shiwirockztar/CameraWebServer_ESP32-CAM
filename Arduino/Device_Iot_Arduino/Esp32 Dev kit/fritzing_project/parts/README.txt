Este directorio es un placeholder para las definiciones de partes Fritzing para ESP32.

Notas:
- No incluí partes .fzpz ni definiciones de piezas en este esqueleto.
- Para obtener un proyecto completamente editable en Fritzing con piezas reales, abre este directorio en Fritzing, importa las partes requeridas desde la biblioteca de Fritzing (ESP32, HC-SR04, relay, buzzer, LEDs) y guarda como `.fzz`.

Instrucciones rápidas para crear el `.fzz` desde este esqueleto:

1. Abre Fritzing.
2. `File` -> `Open` -> selecciona `fritzing_project/breadboard.svg` (o crea un nuevo proyecto y usa estas SVGs como guía).
3. Coloca las partes reales desde la librería y conéctalas.
4. `File` -> `Save As...` y guarda como `wiring_esp32.fzz`.
